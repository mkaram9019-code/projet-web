# Dar Of Luggage

Site web scolaire de consigne à bagages au Maroc (HTML / CSS / JavaScript pur, sans framework).

## Ouvrir le projet
Double-cliquer sur `index.html` : le site s'ouvre dans le navigateur.
Aucun outil à installer (pas de VS Code, pas de Node.js). Une connexion Internet est
utile pour la carte Leaflet, les polices, les photos et le QR code.

## Fichiers
- `index.html` : page d'accueil
- `search.html` : recherche et carte
- `login.html` : connexion
- `main.js` : logique du site (langues, carte, réservation)
- `style.css` : styles (palette définie dans `:root`)
- `images/` : photos des villes et motif zellige
- `logo-gold.svg`, `logo-gold.png` : logo du site
